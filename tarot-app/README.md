# 塔罗牌抽牌 · 单页应用

纯 HTML + CSS + JavaScript 实现，零依赖、无后端，数据保存在浏览器本地
（图片用 IndexedDB 存储，容量不足时自动降级到 localStorage）。双击 `index.html`
即可直接运行，也可用任意静态服务器托管。

## 目录结构

```
tarot-app/
├── index.html          页面骨架与弹窗结构
├── css/
│   └── style.css       全部样式（深色神秘风、3D 翻牌、响应式）
└── js/
    ├── data/
    │   ├── cards.js    78 张牌义数据（唯一数据源）
    │   └── spreads.js  6 种牌阵配置
    ├── core/
    │   ├── storage.js  图片持久化封装（IndexedDB → localStorage → 内存）
    │   ├── skins.js    套系（皮肤）管理
    │   └── tarot.js    洗牌 / 抽牌 / 整体解读逻辑
    ├── ui/
    │   ├── render.js   牌阵渲染与翻牌交互
    │   └── modal.js    弹窗（牌义详情 / 套系管理 / 设置 / 上传）
    └── main.js         入口：初始化、Tab、顶部操作绑定
```

## 使用说明

### 一、上传牌面图片

1. 点击顶部「套系」按钮，打开**套系管理**弹窗。
2. 在下方「当前套系牌面图集」中点击任意一张牌，弹出上传窗口。
3. **拖拽**图片到虚线框内，或**点击**虚线框从本地选择文件。
4. 图片会自动裁剪为 2:3 竖版并缩放（600×900），预览满意后点「保存」。
5. 未上传的牌自动显示占位图（渐变背景 + 牌名 + 序号）；「恢复默认」可删除该牌的自定义图片。

### 二、新建套系（皮肤）

1. 打开「套系管理」弹窗，点击「＋ 新建套系」，输入名称。
2. 新套系会自动成为**当前套系**，之后上传的所有图片都归属于它。
3. 在套系列表中可对每个套系：**使用**（切换）、**重命名**、**删除**、**导出**（JSON 打包全部图片）。
4. 「导入套系」可把之前导出的 JSON 文件还原为一整套牌面。
5. 切换套系后，所有牌阵立即使用新套系的图片。
6. 内置「经典占位」默认套系不可删除。

### 三、新增一个牌阵

只需在 `js/data/spreads.js` 的 `SPREADS` 数组中加一个对象即可，视图与逻辑会自动渲染：

```js
{
  id: 'my-spread',              // 唯一 ID
  name: '自定义牌阵',            // Tab 显示名称
  subtitle: '说明文字',
  count: 4,                     // 抽牌张数（自由抽牌用 null）
  layout: 'line',               // 'line' 横排 | 'choice' 左右对比 | 'cross' 凯尔特十字
  free: false,                  // 是否为自由抽牌
  reversed: true,               // 该牌阵是否允许逆位
  positions: [                  // 位置含义（数量须与 count 一致）
    { id: 'p0', label: '位置一', meaning: '含义说明' },
    { id: 'p1', label: '位置二', meaning: '含义说明' }
    // ...
  ],
  interpretation: '整体解读结语模板'
}
```

> 若使用 `layout: 'cross'`，十字牌阵的坐标在 `js/ui/render.js` 的
> `CROSS_COORDS` 中按位置顺序映射，可按需调整。

## 功能一览

- **6 种玩法**：单张牌 / 圣三角 / 二选一 / 凯尔特十字 / 关系牌阵 / 自由抽牌（1~10 张）。
- **逐张翻牌**：抽牌后牌面朝下，点击逐张翻开；也可「全部翻开」。
- **逆位支持**：可在顶部「设置」全局开关；自由抽牌可单独指定。
- **牌义详情**：翻开的牌可再次点击，查看正/逆位含义、关键词、元素/星座与建议。
- **整体解读**：所有牌翻开后自动汇总。
- **皮肤管理**：多套系切换、导入导出、单张替换。
